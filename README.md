# Word Ladder - Shortest Transformation Path

## About the Project
A C++ based Word Ladder application that finds the shortest transformation path between a starting word and a target word by changing one character at a time.

## Features
- Finds the shortest word transformation path.
- Uses Breadth-First Search (BFS).
- Uses a word dictionary stored in `words.txt`.
- Displays the transformation path when available.
- Handles cases where no valid transformation path exists.

## Algorithm Used
- Breadth-First Search (BFS)
- Graph Traversal
- Shortest Path

## Technologies Used
- C++
- Data Structures & Algorithms
- STL
- Queue
- Unordered Set

## How to Run

1. Clone or download this repository.
2. Make sure `main.cpp` and `words.txt` are in the same folder.
3. Compile the program:

g++ main.cpp -o wordladder
